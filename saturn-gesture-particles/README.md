# Saturn · 手势粒子土星

基于 Three.js + MediaPipe Hands 的实时交互 3D 粒子系统。摄像头检测手掌张合，
控制一颗由 10 万+ 粒子构成的土星的缩放、亮度与混沌状态。

## 运行

摄像头 API 要求页面运行在 `https://` 或 `localhost` 下：

```bash
cd saturn-gesture-particles
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

依赖（Three.js 0.160、MediaPipe Hands）全部通过 CDN 加载，无需安装。

## 交互

| 手势 | 效果 |
| --- | --- |
| 张开手掌 | 土星膨胀、亮度按 ∝ 尺寸² 增强（灯光物理：小暗大亮） |
| 握紧拳头 | 收缩、暗淡 |
| 张到极限 | 粒子逼近屏幕边缘时轨道崩坏：径向炸裂 + 高频布朗/蝇群乱飞 |

无摄像头时自动回退为鼠标滚轮 / 上下拖动控制。右上角按钮切换全屏。

## 实现要点

- **开普勒动力学**：每个星环粒子是一条真实椭圆轨道，顶点着色器内用牛顿迭代解
  开普勒方程 `E − e·sinE = M`；第三定律 `n ∝ a^(-3/2)` 决定各环带角速度，
  第二定律（近点快、远点慢）由椭圆解自然满足。
- **星环结构**：按真实土星环分带采样 —— C/B/A/F 环、卡西尼缝、恩克缝，
  外环偏冰蓝色调。
- **星球本体**：扁球体粒子云，纬度条纹色板，赤道快极区慢的差速自转。
- **混沌临界**：每个粒子有独立崩坏阈值，炸开错落渐进；时间域值噪声叠加
  两组不可通约高频，模拟苍蝇式无规则飞行；同时镜头微颤。
- **画面**：UnrealBloom 辉光随亮度呼吸、加性混合高斯光点、远景星空、暗角。
